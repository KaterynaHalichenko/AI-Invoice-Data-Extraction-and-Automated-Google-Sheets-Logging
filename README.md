# AI Invoice Data Extraction and Automated Google Sheets Logging

## My Role
Workflow Automation and Integration Specialist

---

## Project Overview
This project is an **automated AI-powered workflow** designed for invoice processing and structured data extraction.

The system continuously monitors a cloud storage folder for new invoice files, automatically processes incoming documents, extracts key financial data using AI, and stores structured results in Google Sheets.

The main goal was to eliminate manual data entry, improve data accuracy, and speed up invoice processing for finance and operations workflows.

---

## Workflow Logic

The automation follows a simple pipeline:

- Monitor cloud storage folder for new invoice files  
- Automatically download new documents  
- Extract invoice data using AI-based processing  
- Normalize extracted fields (invoice number, vendor, amount, date, etc.)  
- Store structured data in Google Sheets  

---

## Key Features
- Automated file monitoring in cloud storage  
- AI-based invoice data extraction  
- Structured data normalization  
- Google Sheets integration for database logging  
- Fully automated end-to-end processing  
- No manual data entry required  
- Scalable workflow for high-volume processing
